# EnvStat · 环境监测数据智能分析器

面向环境监测数据的轻量统计分析工具。选一份数据（或导入自己的 CSV），自动完成**描述统计 → 分布诊断 → 相关与回归 → 组间差异检验 → 时间趋势判断**，并把计算结果组织成可直接引用的中文分析结论。

- 纯前端、零构建、零后端：`index.html` + 原生 JavaScript，双击即可运行
- 零第三方依赖：图表是手写 SVG，统计检验是自己实现的算法，不引入任何 CDN
- 计算可复核：全部统计量在浏览器里实时算，页面上能看到每一条结论对应的数字

---

## 一、功能一览

| 模块 | 内容 |
| --- | --- |
| 数据源 | 3 套内置环境监测样例数据；支持拖入 / 选择 CSV（自动识别分隔符、表头、列类型、缺失值）；支持从 Excel 直接粘贴表格 |
| 数据质量概览 | 样本量、完整率、各字段有效值 / 缺失值 / 异常值（Q1−1.5IQR ~ Q3+1.5IQR） |
| 分布特征 | 11 项描述统计、直方图、经验分布函数（ECDF）与正态参照曲线、Jarque-Bera 正态性检验 |
| 相关结构 | 数值变量 Pearson 相关矩阵热力图 + 按 \|r\| 排序的显著性列表 |
| 回归分析 | 一元线性回归：斜率、截距、R²、斜率标准误与 95% 置信区间、残差标准误、散点 + 拟合线 |
| 组间差异检验 | 两组自动用 Welch / Student t 检验（含 Cohen's d、均值差置信区间）；三组及以上自动切换单因素方差分析（含 η²）；箱线图带须线、均值点、异常值点 |
| 时间趋势 | 逐期折线 + 月度均值柱状图 + Mann-Kendall 趋势检验（带结值修正）+ Sen 斜率；对空气质量/地表水指标自动叠加标准限值参考线 |
| 智能解读 | 规则引擎把统计量组织成五段式结论（数据与分布 / 变量关系 / 组间差异 / 时间变化 / 方法与局限）；可选择性接入 OpenAI 兼容接口，由大模型在同样的事实清单上重新表述 |
| 导出 | 一键复制结论、导出 Markdown 分析报告、打印 / 另存 PDF（含打印样式） |

派生分组：数据只有时间列、没有分类变量时，可以按「季节」或「月份」自动派生分组再做方差分析。

## 二、运行方式

### 方式一：直接打开（最简单）

双击 `index.html`，用 Chrome / Edge 打开即可。所有脚本都是普通 `<script>`，不依赖模块加载，`file://` 下也能正常运行。

### 方式二：本地起服务（推荐，行为与线上一致）

```bash
cd env-analyzer
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765/
```

### 方式三：部署到 GitHub Pages

1. 新建仓库，把本项目全部文件推送到 `main` 分支（`index.html` 必须在仓库根目录）；
2. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存；
3. 等 Actions 构建完成后访问 `https://<用户名>.github.io/<仓库名>/`。

## 四、数据说明

内置三套数据**均为示例数据**，按公开监测数据的统计特征构造（固定随机种子，每次打开完全一致），用于演示分析流程，**不代表任何站点实测值**。

| 数据集 | 规模 | 字段 | 设计意图 |
| --- | --- | --- | --- |
| 杭州市某国控站点空气质量（2024 逐日） | 366 行 | 日期、PM2.5、PM10、SO2、NO2、CO、O3、AQI | 完整一年、带季节项与冬季污染过程，用于趋势、相关、回归；AQI 按 HJ 633-2012 的分指数算法由 6 项污染物合成 |
| 某河段治理前后水质监测 | 72 行 | 采样月份、断面（3）、时期（2）、氨氮、高锰酸盐指数、总磷、溶解氧、pH | 2 水平分组 → Welch t 检验（治理前后氨氮均值 6.03 → 2.68 mg/L） |
| 三种处理工艺 COD 去除效果对比 | 36 行 | 工艺（3）、批次、进水COD、出水COD、去除率 | 3 水平分组 → 单因素方差分析（F(2,33)=12.58，η²=0.433） |

设计时刻意保留了一些**不显著**的分析结果（如按断面分组的氨氮差异、进水COD 与出水COD 的回归），用于说明“统计工具的价值不只是给出显著性”。

导入自有数据：CSV 首行为表头；列类型按取值自动推断（≥90% 可解析为数字 → 数值列，符合年月日格式 → 时间列，其余为分类列）；空单元格按缺失处理。

## 五、方法说明

| 指标 | 口径 |
| --- | --- |
| 均值 / 标准差 | 样本标准差（除以 n−1）；变异系数 = s / \|x̄\| |
| 分位数 | 线性插值（R type-7，与 numpy / pandas 默认一致） |
| 偏度 / 峰度 | 三阶、四阶矩的总体形式（与 `scipy.stats.skew/kurtosis` 默认 `bias=True` 一致），峰度为超额峰度 |
| 正态性 | Jarque-Bera：JB = n/6·(S² + K²/4)，服从 χ²(2) |
| Pearson 相关 | r 的显著性用 t = r·√((n−2)/(1−r²))，双侧 p |
| 一元回归 | OLS；斜率标准误 = √(MSE/Sxx)；95% CI 用 t(n−2) 分位数 |
| 两样本检验 | 默认 Welch（不假设方差齐性），也可切换 Student；效应量 Cohen's d 用合并标准差 |
| 方差分析 | 单因素固定效应；F = MSB/MSW；效应量 η² = SSB/SST |
| 趋势检验 | Mann-Kendall（带结值修正，连续修正 ±1），斜率用 Sen 中位数估计 |
| 趋势序列 | 有 ≥4 个月时对**月度均值**做 MK，避免逐日自相关使 p 值过于乐观 |

分布函数（t / F / χ² 的累积分布与分位数）均为自行实现：不完全贝塔函数用连分式展开，不完全伽马函数用级数 + 连分式，Lanczos 近似计算 logΓ。

### 数值正确性验证

```bash
cd tests
python make_reference.py > reference.json   # 需要 numpy + scipy
node verify.js
```

对同一组数据，把本项目的 28 项统计量与 scipy 逐项比对，相对误差 < 1e-12（组合检验的 p 值受双精度下溢影响除外）。

## 六、已知局限

- 只做一元线性回归；多元回归、非线性拟合、事后多重比较（Tukey HSD）尚未实现，页面上对这些后续步骤有文字提示；
- 趋势检验假设序列独立，虽有月度聚合缓解，但存在强自相关时仍会高估显著性；
- 时间列只识别 `YYYY-MM-DD` / `YYYY-MM` / `YYYY年MM月` 等常见格式；
- 大模型解读需要用户自备接口与密钥（仅存本机 localStorage），不做任何数据上传以外的处理；未配置时全部走本地规则引擎；
- 结论中的数字都可回溯到页面上的表格，但统计显著不等于因果，环境质量评价还需结合采样规范、检出限与标准限值。

## 七、制作说明（AI 协作）

本作品用 WorkBuddy 完成，人机分工大致是：

- **人**：确定选题与分析口径（选哪些检验、按什么标准判定）、设计信息架构、判断每个图表该不该出现、复核数值是否合理、决定“哪些结论不能写”；
- **AI**：生成页面骨架与样式、实现统计算法与 SVG 图表、按需求迭代（修复图表缩放导致的字号过小、柱状图标签重叠、阈值标注被折线穿过、分组名暴露内部键名等问题）、编写测试脚本与本文档。

完整交互过程与关键迭代节点见实验报告补充材料。
